# Technology logos

These files come from two open-source icon libraries:

- **Simple Icons** (https://simpleicons.org), CC0 1.0: `databricks.svg`, `telegram.svg`
- **Devicon** (https://devicon.dev), MIT licence: `python.svg`, `git.svg`, `apachespark.svg`, `azure.svg`, `azuredatafactory.svg`, `githubactions.svg`

`microsoftfabric.png`, `powerbi.png` and `deltalake.png` were supplied by the site owner.

To add a logo, put the file here, then add a line to `STACK_LOGOS` in `app.js` that maps the stack name (lowercase) to the file name.

The logos are trademarks of their owners. They are used only to show which technologies a project uses, and they don't imply endorsement.
